## 依頼サマリ
アプリケーションの設計と開発計画を立ててほしい
アプリケーションの概要は[document](./idea.md)に記載している

## 依頼詳細
ここから、複数チームに分かれて、具体的な設計と開発計画を立て、結果をmarkdownで出力してほしい
以下のチームを組成：
1. first-architect-agent: [document](./idea.md)を参照して、開発のための設計や技術選定の概観を記載した設計ドキュメントを作成する。技術的に不確実な点があれば後続のagentに調査を依頼するために情報をドキュメント化する。
2. research-agent: 技術的に不確実な点について、インターネットでベストプラクティスを調査し、調査結果を設計ドキュメントに追記する。
3. red-agent: 作成された設計ドキュメントを参照し、元のアイデアからの齟齬がないか、整合性が取れていない点はないか、オーバーエンジニアリングな点はないかをクリティカルシンキングでレビューする。
4. final-architect-agent: red-agentのコメントを受け、最終的な設計をブラッシュアップして作成する
5. roadmap-agent: 最終的な設計に対して、実装のステップを定義し、ロードマップを作成する。実装は最小構成のアプリケーションから徐々に機能拡張していくように計画され、各ステップで動くソフトウェア（MVP）がアウトプットされる

## 進行上の注意
* 不足条件は仮定で進め、仮定は先頭に明記してください。
* 5分ごとに進捗共有し、30分で1案に統合してください。
* 構築時はTDDを遵守するような計画にしてください。
