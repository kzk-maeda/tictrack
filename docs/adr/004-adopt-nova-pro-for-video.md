# ADR 004: Amazon Nova Pro をビデオ分析に採用

## ステータス

承認済み（2026-03-06）

## 背景

ビデオ分析機能で使用するモデルとして以下を検討：

### 選択肢 1: Claude Sonnet 4.5（Vision API）
- 画像分析能力が高い
- ビデオは静止画フレームに分割して分析
- テキスト生成品質が高い

### 選択肢 2: Amazon Nova Pro
- ビデオネイティブ分析
- フレーム間の時系列関係を理解
- コスト効率が良い

### 問題点
- チックは時系列的な動作（頭を振る、肩をすくめるなど）
- 静止画では動作の「開始」「終了」が判断しにくい
- コスト制約あり（月 1,000 回の分析を想定）

## 決定

**Amazon Nova Pro をビデオ分析に採用する。**

理由：
1. **ビデオネイティブ**: フレーム間の時系列関係を理解し、動作の開始・終了を検出可能
2. **コスト効率**: ~$0.004/video（Claude より約 90% 安い）
3. **Bedrock 統合**: AgentCore Runtime から直接呼び出し可能
4. **品質**: チックの検出精度がテストで十分

コスト試算：
- Nova Pro: $0.004 × 1,000 = **$4/月**
- Claude Sonnet（静止画×10フレーム）: $0.048 × 1,000 = **$48/月**

## 結果

### ポジティブ
- ✅ コストが大幅削減（90% 削減）
- ✅ ビデオ分析品質が向上（時系列情報を活用）
- ✅ チックの「強度」を時系列で評価可能
- ✅ Transcribe と統合して音声チックも検出

### ネガティブ
- ❌ Claude ほどテキスト生成品質は高くない
- ❌ プロンプトチューニングが必要
- ❌ Nova Pro のリージョン制約（一部リージョンのみ）

### トレードオフ
- **テキスト品質** vs **ビデオ分析能力** → ビデオ分析能力を優先
- **汎用性** vs **コスト効率** → コスト効率を優先

## 補完戦略

- **テキスト生成**: Nova Pro の出力を Claude Haiku で後処理
- **音声分析**: Transcribe で音声文字起こし → Claude Haiku で分析
- **マイクロガイド**: Claude Haiku を使用（テキスト品質重視）
